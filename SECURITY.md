# Security Policy

## Supported Versions

Only the latest release of Repo Rizz is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | ✅ Yes    |
| < v0.1  | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, report it privately to the maintainers.

### Contact Info
Please email reports to: **[INSERT_SECURITY_CONTACT_EMAIL]** (Maintainers: replace this placeholder with your security email address).

### What Information to Include
To help us triage and resolve the issue quickly, please include the following details in your report:
- **Type of issue** (e.g., buffer overflow, SQL injection, information disclosure).
- **Paths, endpoints, or components affected**.
- **Step-by-step instructions to reproduce** the vulnerability (include code snippets, request payloads, or screenshots if applicable).
- **Potential impact** and how an attacker could exploit it.

### Responsible Disclosure Expectations
- **Triage**: We will acknowledge receipt of your report within 48 hours and provide a preliminary response.
- **Resolution**: We aim to resolve verified vulnerabilities within 30 days of receipt.
- **Coordinated Disclosure**: We ask that you give us reasonable time to investigate and patch the vulnerability before disclosing it publicly to ensure the safety of our users.

### What NOT to Disclose Publicly
- Do not post vulnerability details, exploits, or proof-of-concept scripts in public issues, discussions, pull requests, or third-party forums until a patch has been released and coordinated disclosure has been agreed.
