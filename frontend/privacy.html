Privacy Policy

Last updated: August 2026

Data Collection

Repo Rizz analyzes public GitHub repositories only. We fetch publicly available repository metadata (file tree, README, package.json, etc.) via the GitHub API. No private data is accessed.

No Account Required

Repo Rizz does not require user accounts, login, or personal information. Analyses are performed on-demand and are not stored persistently unless you choose to save them locally in your browser.

Local Storage

Analysis history may be stored in your browser's localStorage for your convenience. This data never leaves your device.

Third-Party Services

We use the GitHub API to fetch repository data and an optional AI provider for enhanced insights. API keys are stored server-side only and are never exposed to the client.

Contact

For privacy concerns, open an issue on our GitHub repository.
